Makes every NUnit test log itself into the test helper monitor, with nothing to write in the test
project.

Each test becomes a log group, and a failure logs its message and stack trace. The assembly attribute
that does it is generated by MSBuild files shipped in `buildTransitive`, so referencing the package is
enough.

Other CK.Testing packages plug their own NUnit attributes in by appending to the same MSBuild property
rather than replacing it.
